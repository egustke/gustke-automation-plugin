# Gustke Automation - Plugin fuer Claude

Werkstatt-Werkzeuge von Gustke Automation direkt in Claude: Gmail, Lexware, Firmenlaufwerk und Listen, ERP, Kalkulation, Gedaechtnis und Firmenwissen.

Voraussetzung: die Werkstatt-Programme von Gustke Automation sind auf dem Rechner installiert (Setup). Das Setup richtet das Plugin auch gleich in Claude ein; dieses Verzeichnis ist fuer Rechner ohne Setup-Einrichtung.

Installation von Hand:

    claude plugin marketplace add egustke/gustke-automation-plugin
    claude plugin install gustke-automation@gustke-automation

Die Werkzeuge selbst liefert das Setup der Werkstatt-Programme; dieses Repo enthaelt nur die Plugin-Huelle (Startskript, Skills, Befehle).
